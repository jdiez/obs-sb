# Sources

Immutable archive of original documents. Files here are never modified after deposit.

## Rules

- When processing an inbox item, copy the original file here BEFORE transforming it.
- File naming: keep the original filename. If a collision occurs, suffix with ` (2)`, ` (3)`, etc.
- Never edit files in this directory. They are provenance records.
- The corresponding processed note in `notes/` should reference its source via a `source-file` property in YAML frontmatter: `source-file: "[[sources/Original Filename]]"`.
