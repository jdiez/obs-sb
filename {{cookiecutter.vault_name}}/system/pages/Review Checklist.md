# Review Checklist

## Weekly Review (Sunday)

- [ ] Read all daily journal entries for the week
- [ ] Review completed tasks — anything to celebrate?
- [ ] Review meetings — any follow-ups missed?
- [ ] Check overdue tasks — reschedule or drop
- [ ] Check active projects — any stalled without next actions?
- [ ] Identify orphan notes — assign subjects/categories
- [ ] Plan top 3 priorities for next week
- [ ] Write weekly summary in `journal/YYYY/weekly/`

## Monthly Review (1st of Month)

- [ ] Read all weekly summaries for the month
- [ ] Review goals — on track, behind, or pivoted?
- [ ] Check project statuses — any to archive or escalate?
- [ ] Review new notes — any patterns or recurring themes?
- [ ] Extract lessons into Permanent Notes if warranted
- [ ] Review reading list — anything to prioritize?
- [ ] Update goal target dates if needed
- [ ] Write monthly summary in `journal/YYYY/monthly/`

## Quarterly Review (Optional)

- [ ] Re-read all monthly summaries
- [ ] Assess goals — keep, revise, or retire?
- [ ] Archive completed projects with retrospective
- [ ] Review subjects — any new ones emerging?
- [ ] Clean up stale notes (status: idea for 90+ days)
- [ ] Back up vault
