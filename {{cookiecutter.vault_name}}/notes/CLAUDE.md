# Notes

ALL knowledge notes live here in a flat structure. No subfolders — ever.

## Rules

- Every file must have YAML frontmatter with `categories`, `subjects`, `status`, and `type`.
- Categories and subjects use `[[wikilink]]` syntax pointing to files in `categories/` and `subjects/`.
- A note can have multiple categories and multiple subjects.
- Organization happens through properties, not folder hierarchy.
- Journal/daily entries do NOT go here — they go in `journal/`.
