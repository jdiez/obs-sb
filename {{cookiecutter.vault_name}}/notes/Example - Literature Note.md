# Building a Second Brain

## Summary

Tiago Forte's PARA method organizes information into Projects, Areas, Resources, and Archives. The core insight is that notes should be organized by actionability, not by topic. This vault uses a similar philosophy — properties over folders.

## Key Ideas

- Capture everything that resonates — don't filter too early
- Organize for action, not for categorization
- Distill notes progressively — highlight, bold, summarize
- Express what you know by creating and sharing

## Quotes

> Your Second Brain is not a library — it's a workshop.
