# Inbox

This is the capture zone. Everything unprocessed lands here.

## Rules

- Files here have NOT been organized yet — they may lack proper frontmatter.
- When processing inbox: read each file, determine its category and subjects, add YAML frontmatter with `[[wikilink]]` properties, then move the file to `notes/`.
- If a file is a journal entry, move it to `journal/YYYY/MM/` (year-based hierarchy) instead.
- After processing, inbox should be empty.
